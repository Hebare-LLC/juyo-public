# juyo-public
Publicly available documents

## Juyo website

The website consists of three standalone HTML pages with no build step or dependencies:

- [Privacy policy](juyo-privacy-policy.html)
- [Delete your account](delete-your-juyo-account.html)
- [Delete your data](delete-your-juyo-data.html)

Open `index.html` or any page directly in a browser to preview it.

To publish with GitHub Pages, go to **Settings → Pages**, select **Deploy from a branch**, and choose the branch containing these files and **/ (root)**. Once deployed, open:

- `https://hebare-llc.github.io/juyo-public/`
- `https://hebare-llc.github.io/juyo-public/juyo-privacy-policy.html`
- `https://hebare-llc.github.io/juyo-public/delete-your-juyo-account.html`
- `https://hebare-llc.github.io/juyo-public/delete-your-juyo-data.html`

The pages are starter content. Hebare LLC must supply and publish its actual privacy policy and verified deletion procedures before using them as official policy or deletion guidance.
